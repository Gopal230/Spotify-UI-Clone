Spotify UI Clone:-
A responsive front‑end clone of the Spotify Web Player interface built using HTML and CSS.  
This project replicates the look and feel of Spotify’s design while practicing layout, styling, and interactive elements.

---
Features:-
- Styled components replicating Spotify’s interface
- Interactive elements (buttons, hover effects, navigation bar)

Tech Stack:-
- HTML
- CSS

Project Structure:-
index.html → Main page
style.css  → Styling and layout
